# Hospital Inventory Hub (65)

Crie um sistema web responsivo para gestão de logística e estoque de materiais hospitalares. A tela inicial deve ser um painel mostrando uma lista de 'Locais' (hospitais da região). Ao clicar em um hospital, o usuário deve ser levado a uma página detalhada dividida em duas abas principais: 'Estoque Transitório' e 'Estoque Consignado'. Dentro de cada aba, crie uma tabela e um botão para adicionar novos materiais. O formulário de adição deve conter os campos: Nome do Material (ex: Caixas de OPME, Implantes), Quantidade de Caixas, Data de Entrega (DatePicker) e Data de Retirada (DatePicker). Por enquanto, crie apenas o visual (front-end) usando dados fictícios, com um design limpo, focado em usabilidade operacional e usando componentes do shadcn/ui.
